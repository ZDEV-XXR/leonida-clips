# Leonida Replay Uploader - Privacy Policy

Leonida Replay Uploader is a private tool used only by the owner of the Leonida Replay YouTube channel
to upload that channel's own videos and thumbnails through the YouTube Data API.

- It accesses only the owner's own YouTube channel, and only to upload videos, set thumbnails and
  update video details.
- It does not collect, store, sell or share any data about other users.
- The access token is stored as an encrypted GitHub Actions secret and is used only by this repository's
  upload workflow.
- Access can be revoked at any time at https://myaccount.google.com/permissions.
